# 竞品价格监控系统

面向采销 / 电商运营的自动化价格监控：定时采集竞品商品页价格，写入历史库，自动生成价格变动日报与跟价建议。

- **在线演示（项目介绍 + 周报样例）**：https://46bzvs7m64-gif.github.io/price-monitor/
- **直接看周报**：https://46bzvs7m64-gif.github.io/price-monitor/report.html

## 功能

- 采集管道：urllib 抓取商品页 → 正则解析价格；网络失败自动回退离线夹具，监控不中断
- 历史库：`data/price_history.json` 按 SKU 沉淀每日价格，同日重复运行去重覆盖
- 自动对比：与上次价、7 日前价对比，降价超 5% 输出跟价提示
- 报告：自动生成 `report.md` 和 `report.html`
- 商品配置化：新增监控商品只需改 `products.json`，不用改代码

## 使用（Python 3，零依赖）

```bash
python price_monitor.py
```

配合系统计划任务（Windows 任务计划程序 / crontab）每天定时执行，即可实现日报推送。

## 数据说明

`fixtures/` 是 3 个跑鞋商品页离线夹具（安踏 / 迪卡侬 / 李宁，演示用非真实页面）；`products.json` 中的 `url.example` 为占位链接。真实使用时替换为京东 / 天猫真实链接并按页面结构调整 `price_pattern`。电商大站普遍有反爬，生产环境建议改接平台开放 API / 联盟接口。

## 面试可讲

- 采销的核心日常之一是盯竞品定价，监控频率决定跟价反应速度
- 系统设计：采集与分析解耦（配置驱动）、失败兜底、历史数据可追溯
- 报告直接给动作而不是只给数字：降价→评估跟价/加券，涨价→维持现价抢量
