竞品价格监控系统

面向采销 / 电商运营岗位场景：定时采集竞品商品页价格 → 沉淀历史库 → 自动对比波动并生成带跟价建议的周报。Python 标准库实现，零第三方依赖，可挂系统计划任务每日自动运行。

查看最新监控周报 → GitHub 源码

处理流程

定时抓取商品页→ 正则解析价格→ 失败回退离线夹具→ 写入历史库(去重)→ 环比 / 7日对比→ 生成 MD+HTML 周报

采集与分析解耦：新增监控商品只需改 products.json 配置，无需改动代码；网络异常自动兜底，保证监控任务不中断。

核心能力

  • 价格采集：urllib 请求 + 可配置正则解析，支持多 SKU 批量监控
  • 历史沉淀：按 SKU 保存每日价格到 JSON 历史库，同日重复运行自动去重覆盖，支持回溯任意时点价格
  • 智能预警：与上次价、7 日前价双重对比，降价超 5% 自动标记并输出跟价提示
  • 动作导向：报告不只给数字——降价提示评估跟价/加券，涨价提示维持现价抢量，平稳则持续观察
  • 双格式输出：同时生成 Markdown（存档/推送）与 HTML（可视化汇报）报告
